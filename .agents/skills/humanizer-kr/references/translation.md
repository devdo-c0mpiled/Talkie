# 번역투 패턴 (패턴 26-33)

한국어 AI 텍스트에서 가장 빈번하게 나타나는 카테고리. 영어 훈련 데이터의 영향으로 영어(및 일부 일본어) 구문을 한국어로 직역한 표현이 나타난다.

## 근거

- **LREAD** (Park & Han, 연세대, ArXiv 2601.19913, 2026) — 번역투(translationese)를 LLM 생성 한국어 텍스트의 **핵심 탐지 단서**로 명시적으로 확인. 전문가 루브릭 적용 시 탐지 정확도 60%→90-100% 향상
- **국립국어원 새국어생활 제22권 제1호** (2012) — "영한 번역에 나타난 번역투 문장" (김순영). 구문 형식 전이(수동태, have 구문), 굴절 형식 전이(복수 -들), 전치사구 전이 체계적 분류
- **국립국어원 새국어생활 제22권 제1호** (2012) — "일한 번역에 나타난 번역투 문장". 일본어 번역투의 특성(~적, において 등)
- **최희경** (고려대, 번역학연구 제17권 1호, KCI 2016) — 코퍼스 기반 번역투 실증 분석. '~로부터'(from), '~를 통해'(through) 등의 정량적 빈도 비교
- **김정우** (경남대, 번역학연구 제8권 1호, KCI 2007) — 번역투를 어휘적/통사적/화용적 층위에서 다차원적으로 정의


## 패턴 26: 피동 남용

### 영어 수동태 → 한국어 피동

| 영어 | AI 한국어 (번역투) | 자연스러운 한국어 |
|------|-------------------|-----------------|
| was decided by | ~에 의해 결정되었다 | ~이 결정했다 |
| is being used | 사용되어지고 있다 | 쓰고 있다 |
| was affected by | ~에 의해 영향을 받았다 | ~이 영향을 미쳤다 |
| was established | 설립되어졌다 | 설립했다 / 세웠다 |

### 이중 피동 (문법 오류)

다음은 틀린 표현이다:
- 쓰여**지다** → 쓰이다
- 만들어**지다** → (이미 피동) 만들어지다는 허용
- 되어**지다** → 되다
- 읽혀**지다** → 읽히다
- 보여**지다** → 보이다

### 추가 예시

**Before:**
> 이 정책은 정부에 의해 시행되어졌으며, 국민들에 의해 지지를 받고 있다. 변화가 사회 전반에 걸쳐 느껴지고 있다.

**After:**
> 정부가 이 정책을 시행했고 국민도 지지하고 있다. 사회 전반에서 변화를 느낄 수 있다.


## 패턴 27: `~에 대하여/관하여`

### 대체 패턴

| 번역투 | 자연스러운 한국어 |
|--------|-----------------|
| ~에 대하여 논의하다 | ~을 논의하다 |
| ~에 관하여 설명하다 | ~을 설명하다 |
| ~에 대한 이해 | ~을 이해하는 것 |
| ~에 관한 정보 | ~ 정보 |
| ~에 대해서 걱정하다 | ~을 걱정하다 |

### 예외

"~에 대한 태도", "~에 대한 입장"처럼 대격으로 바꿀 수 없는 경우는 유지한다.

### 추가 예시

**Before:**
> 프로젝트 일정에 대하여 팀원들과 논의하고, 예산 문제에 관하여 경영진에게 보고했다.

**After:**
> 프로젝트 일정을 팀원들과 논의하고 예산 문제를 경영진에게 보고했다.


## 패턴 28: `~하기 위하여`

### 대체 패턴

| 번역투 | 자연스러운 한국어 |
|--------|-----------------|
| ~하기 위하여 | ~하려고 |
| ~하기 위해서 | ~하려면 |
| ~하기 위한 | ~하는 / ~할 |
| ~을 위하여 | ~하려고 / ~하도록 |

### 추가 예시

**Before:**
> 생산성을 높이기 위하여 새로운 도구를 도입했다. 오류를 줄이기 위해서 자동화된 테스트를 구축했다.

**After:**
> 생산성을 높이려고 새로운 도구를 넣었다. 오류를 줄이려면 자동화된 테스트가 필요했다.


## 패턴 29: `~을 가지다`

### 대체 패턴

| 번역투 | 자연스러운 한국어 |
|--------|-----------------|
| 특성을 가지고 있다 | 특성이 있다 / ~하다 |
| 관심을 가지다 | 관심이 있다 / 관심을 두다 |
| 의미를 가지다 | 의미가 있다 |
| 영향력을 가지다 | 영향력이 있다 / 영향을 미치다 |
| 차이를 가지다 | 차이가 있다 / 다르다 |

### 추가 예시

**Before:**
> 이 언어는 독특한 문법 구조를 가지고 있으며, 풍부한 어휘를 가지고 있다.

**After:**
> 이 언어는 문법 구조가 독특하고 어휘가 풍부하다.


## 패턴 30: `~로부터`

### 대체 패턴

| 번역투 | 자연스러운 한국어 |
|--------|-----------------|
| ~로부터 받다 | ~에서/~에게서 받다 |
| ~로부터 시작되다 | ~에서 시작되다 |
| ~로부터 배우다 | ~에게서 배우다 |
| ~로부터 영감을 받다 | ~에서 영감을 얻다 |

### 참고

"~로부터"가 적절한 경우: 공간적 기점을 나타낼 때 ("서울로부터 100km" → 이것도 "서울에서 100km"가 더 자연)


## 패턴 31: `~을 통해`

### 대체 패턴

| 번역투 | 자연스러운 한국어 |
|--------|-----------------|
| ~을 통해 하다 | ~(으)로 하다 |
| ~을 통해 알다 | ~(으)로 알다 |
| ~을 통해 배우다 | ~에서 배우다 |
| ~을 통해 확인하다 | ~에서 확인하다 |

### 예외

"경험을 통해 배우다"처럼 수단보다 과정을 강조하는 경우는 유지할 수 있다.


## 패턴 32: `~에 있어`

### 대체 패턴

| 번역투 | 자연스러운 한국어 |
|--------|-----------------|
| ~에 있어서 | ~에서 |
| ~에 있어 중요한 | ~에서 중요한 |

일본어 "において"의 영향. 거의 모든 경우 "~에서"로 대체 가능하다.


## 패턴 33: `~것이다/것입니다` 남용

### 발현 형태

- "~할 것입니다" (예정)
- "~일 것입니다" (추측)
- "~한 것입니다" (설명)
- "~인 것입니다" (강조)

### 대체 패턴

| 번역투 | 자연스러운 한국어 |
|--------|-----------------|
| 발전할 것입니다 | 발전한다 / 발전할 전망이다 |
| 가능할 것입니다 | 가능하다 |
| 좋을 것입니다 | 좋다 |
| 필요한 것입니다 | 필요하다 |
| ~인 것입니다 | ~이다 |

### 추가 예시

**Before:**
> 이 기술은 더욱 발전할 것이며, 우리의 삶을 크게 변화시킬 것입니다. 이러한 변화는 불가피한 것이며, 우리가 적응해야 하는 것입니다.

**After:**
> 이 기술은 더 발전하고 삶도 크게 바뀐다. 이런 변화는 피할 수 없고 적응해야 한다.
