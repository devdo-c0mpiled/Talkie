## 패턴 9: 불필요한 한자어

### 전체 변환 목록

| 한자어 | 쉬운 말 | 비고 |
|--------|---------|------|
| 진행하다 | 하다 | "회의를 진행하다" → "회의를 하다" |
| 실시하다 | 하다 | "설문을 실시하다" → "설문을 하다" |
| 위치하다 | 있다 | "서울에 위치하다" → "서울에 있다" |
| 개최하다 | 열다 | "행사를 개최하다" → "행사를 열다" |
| 수행하다 | 하다 | "작업을 수행하다" → "작업을 하다" |
| 도출하다 | 얻다/내다 | "결론을 도출하다" → "결론을 내다" |
| 발생하다 | 생기다/나다 | "문제가 발생하다" → "문제가 생기다" |
| 존재하다 | 있다 | "차이가 존재하다" → "차이가 있다" |
| 제공하다 | 주다/내놓다 | "서비스를 제공하다" → "서비스를 주다" |
| 상승하다 | 오르다 | "가격이 상승하다" → "가격이 오르다" |
| 감소하다 | 줄다 | "비용이 감소하다" → "비용이 줄다" |
| 확인하다 | 보다/알아보다 | 문맥에 따라 |
| 구축하다 | 만들다/세우다 | "시스템을 구축하다" → "시스템을 만들다" |
| 유지하다 | 지키다/이어가다 | 문맥에 따라 |

### 주의

학술/공식 문체에서는 한자어가 적절할 수 있다. 문체 감지 결과에 따라 판단한다. 블로그/에세이에서는 적극적으로 쉬운 말로 바꾼다.


## 패턴 10: 복수형 `-들` 남용

### 규칙

이미 복수를 나타내는 수량 표현이 있으면 `-들` 불필요:
- 많은 학생**들** → 많은 학생
- 여러 가지 방법**들** → 여러 가지 방법
- 모든 참가자**들** → 모든 참가자
- 각종 프로그램**들** → 각종 프로그램

`-들`이 자연스러운 경우:
- 수량 표현 없이 복수를 명시할 때: "아이들", "사람들", "친구들"
- "그들", "우리들" 같은 관용적 표현


## 패턴 11: 대명사 남발

### 한국어와 영어의 차이

영어: "The framework is fast. **It** supports multiple languages. **It** has good documentation."
한국어: "이 프레임워크는 빠르다. 여러 언어를 지원하고 문서화도 잘 되어 있다." (주어 생략)

### 제거 대상

- "그것은/이것은" → 주어 생략
- "그녀는/그는" → 이름 사용 또는 생략
- "이러한/그러한" → 구체적 표현 또는 생략
- "그들은" → 구체적 지칭 또는 생략


## 패턴 12: 지시관형사 과다

"해당", "본", "당", "상기" 등은 법률/행정 문서에서 쓰이는 표현이다. 일반 글에서는 "이", "그", "저" 또는 생략이 자연스럽다.


## 패턴 13: 주어 생략 미흡

### 생략 기준

- 직전 문장과 같은 주어면 생략
- 문맥에서 명확하면 생략
- 새로운 주어가 등장할 때만 명시

### 추가 예시

**Before:**
> 이 팀은 매주 회의를 합니다. 이 팀은 월요일마다 스프린트를 계획합니다. 이 팀은 금요일에 회고를 합니다.

**After:**
> 이 팀은 매주 회의를 한다. 월요일마다 스프린트를 계획하고 금요일에 회고를 한다.


## 패턴 14: `의` 남용

### 판단 기준

`의`가 2번 이상 연속되면 거의 확실히 문제다:
- "회사**의** 올해**의** 매출**의** 증가" → "회사 올해 매출 증가"

`의`를 쓰지 않아도 의미가 통하면 빼라:
- "한국**의** 경제" → "한국 경제"
- "프로젝트**의** 목표" → "프로젝트 목표"

## 패턴 17: 동의어 순환

### AI 반복 페널티의 산물

AI가 "이 프레임워크", "해당 도구", "이 솔루션", "해당 플랫폼"을 순환하며 같은 대상을 지칭한다. 한국어에서는 주어를 생략하거나 같은 이름을 반복하는 것이 자연스럽다.

### 판단 기준

같은 대상을 3개 이상의 다른 이름으로 지칭하면 동의어 순환을 의심한다.
