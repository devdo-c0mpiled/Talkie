# 캐릭터 모션 사용법

승인된 2D 토끼 이미지로 대기·듣기·말하기·인사 모션을 재생한다. 정적 파일과 Web Component로 구성되어 별도 API 키가 필요하지 않다.

## 미리보기

```sh
npm ci
npm run dev
```

터미널에 표시된 주소의 `/mascot/`를 연다. 상태 버튼, 통화 흐름 재생, 일시정지, 속도 조절로 모션을 확인할 수 있다. 마이크 반응은 로컬 음량만 읽으며 녹음하거나 전송하지 않는다. 마이크 접근에는 localhost 또는 HTTPS가 필요하다.

## 화면에서 사용

```html
<script type="module" src="/mascot/talkie-mascot.js"></script>
<talkie-mascot state="idle"></talkie-mascot>
```

부모 요소의 너비로 크기를 조절한다. `state`는 `idle`, `listening`, `speaking`, `greeting`을 지원한다. `paused` 속성은 현재 자세를 유지한다. 모션 줄이기 설정에서는 상태별 정지 프레임을 표시한다.

## 음성 세션 연결

`src/mascot-bridge.ts`의 `createMascotBridge()`를 활성 세션당 하나 생성한다.

```ts
import { createMascotBridge } from './mascot-bridge'

const mascot = createMascotBridge()
// 연결 완료
mascot.connected()
// 실제 마이크 입력과 오디오 출력의 정규화된 음량(0~1)
mascot.levels(inputLevel, outputLevel)
// 연결 종료 또는 오류
mascot.ended()
// mascot.error()
```

음량 콜백을 지속적으로 호출해야 출력이 멈춘 뒤 듣기 상태로 돌아온다. 출력 음량이 0.025를 넘으면 말하기 상태를 유지하고 마지막 감지 후 140ms가 지나면 듣기로 전환한다. 전사 텍스트만으로 말하기 상태를 시작하지 않는다. 음소거 시 입력 음량은 0으로 전달한다. 이벤트는 window 전체에 전달되므로 한 화면의 모든 캐릭터가 같은 상태를 받는다.

컴포넌트 클릭·Enter·Space는 인사 모션을 재생한다. 실제 통화 화면에 연결할 때는 이 동작이 통화 상태를 덮어쓰지 않도록 처리해야 한다. 이 PR은 독립 미리보기와 연결 모듈을 제공하며, main에 아직 없는 음성 PoC 화면의 연결 코드는 포함하지 않는다. 실제 통화 연동은 별도 검증이 필요하다.

## 보간 데이터 재생성

`public/mascot/sprites.png`는 4행×4열 원본 시트다. WebGL2에서는 양방향 optical flow로 프레임을 보간한다. 지원되지 않거나 로딩에 실패하면 crossfade로 전환한다. 말하기는 음량에 반응하는 프레임 애니메이션이며 음소 단위 립싱크는 아니다.

uv가 설치된 환경에서 다음 명령으로 `flow.bin`과 `flow.json`을 재생성한다. Python 의존성은 이 재생성 단계에만 필요하다.

```sh
uv run --with opencv-python-headless --with numpy scripts/build-mascot-flow.py
```

원본 PNG는 변경하지 않는다. 이미지 생성 기록은 `public/mascot/provenance.json`, 모션 범위와 후속 작업은 `public/mascot/motion-plan.json`에 있다.
